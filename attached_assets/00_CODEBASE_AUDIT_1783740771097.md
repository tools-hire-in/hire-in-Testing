# Work Order 00 — Existing Content Studio Codebase Audit

## Objective

Understand the existing Content Studio before changing code. Produce an implementation map for the Hire'in Content Intelligence AI MVP.

## Instructions

Do not write migrations or production code in this task.

Inspect:

1. Project structure and runtime
2. Content Studio routes and pages
3. Existing content types and workflow
4. Authentication and session model
5. Existing role enum and centralized feature-to-role registry
6. Database and migration conventions
7. AI provider integrations and prompt storage
8. Existing document/source ingestion
9. Existing rich-text editor
10. Existing content review/approval workflow
11. Existing analytics/events
12. Existing design system and reusable components
13. Existing audit logging
14. Existing test framework
15. Existing environment secrets and provider abstraction

## Deliverable

Create `docs/content-intelligence-codebase-audit.md` containing:

- Current architecture diagram
- Relevant folders/files
- Current data model
- Existing reusable functionality
- Gaps against the architecture contract
- Technical risks
- Security/privacy risks
- Migration constraints
- Recommended implementation sequence
- Exact files expected to change in Work Order 01
- Any conflicts requiring leadership decision

## Non-negotiables

- No new role enum values
- No replacement of existing auth/RBAC
- No broad refactor
- No speculative feature build
- No database changes
- No AI generation changes

## Completion criteria

- Audit document is complete
- Existing Content Studio behavior is unchanged
- Type check/tests remain at their prior state
- Replit summarizes the top five implementation risks
