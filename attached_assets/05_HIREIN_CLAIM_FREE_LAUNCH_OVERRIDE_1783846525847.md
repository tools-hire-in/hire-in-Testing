# Hire’in Content Agent — Claim-Free Launch Override

This instruction supersedes any earlier proof-card launch requirement.

## Final rule

The Agent must not create Hire’in-specific claims unless the user explicitly supplies them.

When no claim is supplied:

- Omit company claims
- Do not invent proof
- Do not show `[NEEDS_PROOF]`
- Create useful educational, thought-leadership, job, or audience-specific content without promotional assertions

When the user supplies a claim:

- Use it as user-provided content
- Preserve qualifiers
- Do not strengthen, quantify, broaden, or repeat it unnecessarily
- Record `claimSource: user_provided`

No Proof Library, proof-card interview, or approval gate is required for this release.
