Why I did not duplicate the full creative library

The original work order already defines HIREIN_CONTENT_CRAFT.md as the authoritative source for the eight hook archetypes, twelve content archetypes, banned list, platform craft, exemplars, and self-edit pass.

Embedding a second copy inside the intelligence pack would create two versions that could drift apart. The cleaner architecture is:

Intelligence Pack: decides what knowledge to load and when
Content Craft: supplies the exact creative rules and exemplars
Proof Library: controls factual claims

That keeps the Agent smart without making the prompt pack bloated.
