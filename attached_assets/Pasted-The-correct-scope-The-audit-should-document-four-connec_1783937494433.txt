The correct scope

The audit should document four connected areas:

Hire-in.com public website
Current internal application
Underlying technical and database architecture
Existing onboarding and training material

The documentation should describe what is currently present and how it works, not what someone thinks the system should become.

Your older architecture material already contains useful historical information about the database, authentication, portals and proposed workflows, but it should not be treated as the current truth unless the present code confirms it. For example, one earlier architecture snapshot listed 27 tables, while the multi-portal document included many proposed tables and roles that may since have changed.

No human intervention requirement

The agent can produce this without pausing for business-owner review.

Use these evidence labels:

CONFIRMED_IN_CODE
CONFIRMED_IN_SCHEMA
CONFIRMED_IN_ROUTE
CONFIRMED_IN_UI
CONFIRMED_IN_EXISTING_GUIDE
INCONSISTENT_ACROSS_SOURCES
CURRENT_BUT_INCOMPLETE
LEGACY_OR_UNUSED
UNABLE_TO_CONFIRM

The agent should not ask questions while creating the initial version. Where something cannot be resolved, it should document the uncertainty rather than block the work.

Each document can be marked:

Status: Current-state automated system reference
Generated from: code, schema, routes, configuration and existing documents
Human approval required: No
Unresolved items: listed within document

This gives you a usable current-state reference immediately while still being honest about areas the code cannot confirm.

Phase 2 — Training consolidation

Using Phase 1:

Map existing guides to features and roles.
Identify only real training gaps.
Update outdated instructions.
Archive duplicate guides.
Create missing training for main live features.
Build role-based onboarding paths.
Reuse existing quizzes or add short knowledge checks.

This approach captures the entire present system, including the website and database, while avoiding duplicate guides and unnecessary human review.
