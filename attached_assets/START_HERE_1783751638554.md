# START HERE — Deploying Your Hire'in Content AI (No Code Needed)

You have two files. Together they replace the entire 7-work-order build for content creation purposes:

1. **HIREIN_MASTER_PROMPT.md** — the "secret sauce": how the AI thinks, the workflow, the guardrails
2. **HIREIN_AI_KNOWLEDGE_BASE.md** — what the AI knows: brand, audiences, pillars, platform rules, validation

## Setup (5 minutes)

**Option A — Claude Project (recommended)**
1. In Claude, create a new Project called "Hire'in Content AI"
2. Paste the Master Prompt into the Project's custom instructions
3. Upload the Knowledge Base as a Project file
4. Done. Every chat in that project is your content creator.

**Option B — Custom GPT / any other tool**
Same idea: Master Prompt = instructions, Knowledge Base = knowledge file.

## How to use it daily

- Heard a real question from a candidate or client? Start a chat:
  `full package: A nurse asked me "how do I know if a travel contract is legit?"`
- Just want the strategy first: `plan: credentialing delays for OR nurses`
- Have an existing draft: `validate` + paste it
- It flags something as **[NEEDS_PROOF]**? That's the system working — go get the real number or approval, paste it back, and it will cite it.

## What you gave up by not building the app (and when to revisit)

- **Multi-user review queues and approvals** → for now, that's you reading the draft. Revisit if 3+ people work in the pipeline.
- **Database of claims/proof with expiry dates** → for now, keep a simple "Approved Proof" doc and upload it to the Project as a second knowledge file. Update it as you win approvals.
- **Performance dashboard** → for now, a spreadsheet of posts + results; paste the top/bottom performers into a chat monthly and ask "what should we change in our approach?"
- **Version history / audit logs** → chat history covers you at this scale.

If Hire'in later grows to a content team of 5+ with compliance sign-offs, the original work-order package becomes worth building — and everything in these two files drops straight into it as the seed data and prompt layer.
